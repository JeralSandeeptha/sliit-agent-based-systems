## Reasonning / Logical Representation

- For the Reasonning, we use `Logical Representation`
- It's a language with some logical rules which is deal with proposition and no ambiguity in representation
- Allowing machines to reason through explicit rules rather than just statistical patterns
- Consists with `Syntax` (well formed sentence) and `Semantics` (define the truth meaning)
